# Ahmad Mujtaba — Portfolio Website

## Files
- `index.html` — portfolio content and page structure
- `style.css` — responsive styling, layout, visual effects, and CSS animations
- `script.js` — mobile menu, scroll reveals, active navigation, and animated canvas background

## Run locally
Open `index.html` in a browser, or use the VS Code Live Server extension.

## Publish with GitHub Pages
1. Create a new GitHub repository, for example `ahmad-mujtaba-portfolio`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish the website.

## Before publishing
- Confirm the email address and phone number are correct.
- Add a real GitHub/LinkedIn profile link if you want those shown.
- Add more project cards as you have additional projects.
- The current education, experience, and project information follows the supplied CV. The wording has been polished for the portfolio.
